# Политика конфиденциальности приложения AdaptiveHz

**Дата вступления в силу**: 10 октября 2026 г.  
**Разработчик**: HealthCraft Team  
**Приложение**: AdaptiveHz — Умная герцовка для Samsung  
**Проект**: [AdaptiveHz на GitHub](https://github.com/shepard639/AdaptiveHz) • [Экосистема HealthCraft](https://healthcraft.pro)

---

### 1. Общие положения
Настоящая Политика конфиденциальности регулирует порядок обработки и обеспечения безопасности информации пользователей мобильного приложения **AdaptiveHz** (далее — «Приложение»).

Разработчик уважает право каждого пользователя на неприкосновенность частной жизни и придерживается принципа абсолютной конфиденциальности: **Приложение не собирает, не хранит, не обрабатывает и не передает третьим лицам никакие персональные или идентификационные данные**.

---

### 2. Сбор и использование информации
1. **Отсутствие доступа к сети Интернет**:
   В файле манифеста Приложения (`AndroidManifest.xml`) полностью отсутствует системное разрешение `android.permission.INTERNET`. Приложение технически изолировано от глобальной сети и не способно осуществлять исходящие или входящие сетевые соединения, передавать телеметрию, трекинг или аналитику.
2. **Персональные данные**:
   Приложение не запрашивает и не обрабатывает: имена, номера телефонов, адреса электронной почты, геолокацию, контакты, мультимедийные файлы, пароли и платежную информацию.
3. **Локальное хранение настроек**:
   Все пользовательские предпочтения (выбранный режим частоты обновления, таймауты бездействия, профили приложений) хранятся исключительно локально на вашем смартфоне во внутреннем защищенном хранилище DataStore Preferences и удаляются при удалении Приложения.

---

### 3. Используемые системные разрешения и их назначение
Для выполнения своих основных системных функций Приложение использует следующие ограниченные разрешения Android:

| Разрешение | Назначение |
| :--- | :--- |
| `WRITE_SECURE_SETTINGS` | **Ключевое разрешение**. Используется исключительно для изменения параметров частоты обновления дисплея (`peak_refresh_rate`, `min_refresh_rate`, `refresh_rate_mode`) в защищенных таблицах Android и Samsung One UI. Выдается пользователем вручную через Shizuku прямо на смартфоне (без ПК) или через компьютер по кабелю (команда ADB). |
| `BIND_ACCESSIBILITY_SERVICE` | **Служба специальных возможностей**. Используется строго для регистрации событий прикосновения к экрану (`TYPE_TOUCH_INTERACTION_START` / `END`) и скролла для мгновенного переключения частоты на 120 Гц, а также для определения текущего активного приложения (для активации профилей экономии батареи, например в YouTube/видеоплеерах). Приложение **не считывает** текст с экрана, введенные символы, пароли или нажатия клавиш. |
| `POST_NOTIFICATIONS` | Используется для отображения текущей частоты обновления (60/120 Гц) в строке состояния One UI и кнопок быстрого переключения в шторке уведомлений. |
| `FOREGROUND_SERVICE` (`specialUse`) | Используется для поддержания фонового монитора строки состояния без выгрузки системой. |
| `QUERY_ALL_PACKAGES` | Используется исключительно для отображения списка установленных на телефоне приложений на вкладке «Приложения», чтобы пользователь мог настроить индивидуальную частоту кадров. Никакие данные об установленных приложениях не передаются вовне. |

### 4. Безопасность данных
Приложение работает строго в локальной песочнице Android Sandbox. Все операции выполняются непосредственно процессором устройства. Исходный код приложения полностью открыт и доступен для публичного аудита в официальном репозитории на GitHub.
